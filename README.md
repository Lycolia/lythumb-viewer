# Lythumb-viewer

ページ内のサムネイル画像をクリックしたときに、拡大して表示する画像ビューアーです。

jQuery不要で、JSとCSSのみで動きます。LightboxやFancyboxの置き換えを目的に開発しました。

## 特長

- 同じグループの画像を前後にめくれるギャラリー表示
- クリック・ダブルタップでの原寸表示、ドラッグでの移動、2本指ピンチでの拡大縮小
- スワイプ・ホイール・矢印キーでの画像切り替え、縦スワイプで閉じる
- サムネイル一覧の表示
- URLハッシュとの連携（`#グループ名-2`で2枚目を直接開く、ブラウザーの「戻る」で閉じる）
- キーボード操作・スクリーンリーダー・視差効果を減らす設定への対応
- 外部ライブラリ・アイコンファイル不要

画像専用です。動画・iframe・HTMLの表示やスライドショーには対応していません。

## 使い方

`lythumb.min.css`と`lythumb.min.js`を読み込み、拡大したい画像へのリンクに`data-lythumb`を付けます。読み込むだけで自動的に有効になり、後から追加したリンクにも反応します。

```html
<link rel="stylesheet" href="/js/lythumb.min.css" />
<script defer src="/js/lythumb.min.js"></script>

<a href="/images/photo1.jpg" data-lythumb="trip" data-caption="海辺の朝">
  <img src="/images/photo1-thumb.jpg" alt="朝日が差す砂浜" />
</a>
<a href="/images/photo2.jpg" data-lythumb="trip" data-caption="港の灯台">
  <img src="/images/photo2-thumb.jpg" alt="白い灯台" />
</a>
```

| 指定           | 使い道                                                                                                                                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<a href>`     | 拡大表示する画像                                                                                                                                                                                                                                   |
| `data-lythumb` | グループ名。同じ値のリンクが1つのギャラリーになります。空にすると1枚だけの表示になります                                                                                                                                                           |
| `data-caption` | 画像の下に表示する説明文。HTMLは解釈せず、文字のまま表示します。省略すると子の`<img>`の`alt`を使います。<br />`data-caption=""`と書くと、`alt`があってもキャプションを表示しません。代替テキストは付けたいが、キャプションは要らない画像に使います |
| 子の`<img>`    | サムネイル一覧に使う画像。`alt`は拡大画像の代替テキストにも使います（ない場合はキャプション）                                                                                                                                                      |

### スクリプトから開く

`Lythumb.open(リンク)`で、`data-lythumb`の付いたリンクの画像を開きます。`Lythumb.close()`で閉じます。

`showModal()`で開いた`<dialog>`の上に重ねるときは、`Lythumb.open(リンク, { container: dialog })`のように表示先を指定します。モーダルの`<dialog>`はいちばん上に表示され、その外側は操作できなくなるため、`<body>`の直下に出したビューアーは隠れてしまいます。表示先の中にある他の要素は、ビューアーを閉じるまで操作できなくなります。表示先や、その祖先に`transform`などを指定すると、ビューアーが画面全体に広がらないので注意してください。

## 操作

| 操作                           | マウス                             | タッチ端末                      | キーボード     |
| ------------------------------ | ---------------------------------- | ------------------------------- | -------------- |
| 前後の画像へ                   | 矢印ボタン、ホイール、左右ドラッグ | 左右スワイプ                    | ← → ↑ ↓        |
| 原寸表示と画面サイズの切り替え | 画像クリック、虫眼鏡ボタン         | ダブルタップ、虫眼鏡ボタン      | —              |
| 拡大中の移動                   | ドラッグ                           | ドラッグ                        | —              |
| 拡大縮小                       | —                                  | 2本指ピンチ                     | —              |
| 操作ボタンの表示切り替え       | 操作しないと数秒で自動的に隠れる   | 画像をタップ                    | —              |
| サムネイル一覧                 | 一覧ボタン                         | 一覧ボタン                      | G              |
| 全画面表示                     | —                                  | —                               | F              |
| 閉じる                         | ×ボタン、背景クリック              | ×ボタン、背景タップ、縦スワイプ | Esc、Backspace |

- ギャラリーはループしません。
- 画面より小さい画像は、原寸より大きくは表示しません。
- Tabキーでのフォーカス移動はビューアーの中だけで循環し、閉じると元のリンクにフォーカスが戻ります。

## URL ハッシュ

グループ名の付いたギャラリーを開くと、URLの末尾が`#trip-2`のように変わります。このURLを直接開くとその画像が表示され、ブラウザーの「戻る」でビューアーが閉じます。番号のない`#trip`は1枚目を開きます。

ページ内のアンカー（`id`）と同じグループ名を付けると、そのアンカーへのリンクでビューアーが開いてしまいます。重ならない名前を付けてください。

## 対応ブラウザー

Microsoft Edge, Android Edgeで動作確認しています。

現行のChrome・Firefox・Safari・iOS Safariでも動くと思いますが、確認していません。

Pointer Events・`inert`・Web Animations APIなどを使っているため、Internet Explorerや古いブラウザーでは動きません。

## 開発

### 確認用ページ

このディレクトリをHTTPサーバーで配信して`demo.html`を開きます。外部への接続は不要です。

```bash
php -S "[::0]:8888"
```

### テスト

```bash
npm i
npm t
```

### 本番用ファイルの作成

```bash
npm run build
```

`dist/`に`lythumb.min.js`と`lythumb.min.css`を出力します。
